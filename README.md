# 💱 Currency Converter

A simple and responsive **Currency Converter** built using **HTML, CSS, and JavaScript**. It allows users to convert amounts between different currencies using exchange rates fetched from an API.

## 🌐 Live Demo

**[View Live Website] (https://rkconverters.netlify.app/)**

## 🚀 Features

* 💱 Convert between multiple currencies
* 🌐 Real-time exchange rates using API
* 🔄 Dynamic currency selection
* 📱 Responsive design
* ⚡ Fast & simple interface
* ❌ Error handling for invalid requests

## 🛠️ Tech Stack

* HTML5
* CSS3
* JavaScript
* Currency Exchange API
